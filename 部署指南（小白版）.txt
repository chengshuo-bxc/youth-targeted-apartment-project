# 青年公寓服务系统 — 部署指南（小白版）

> **适用系统：Windows 10 / Windows 11** | **最后更新：2026年4月**

---

## 一句话说明

这是一个**租房管理系统**，有前台（租客看房/下单）、用户端（个人中心）、管家端（审核订单）、管理员后台（管理全部数据）。运行它需要装 2 个软件，然后敲 3 行命令就能跑起来。

---

## 第一步：安装必须的软件（2个）

### 1. 安装 Node.js（前端 + 后端的运行环境）

> 这是运行本项目的基础软件，没有它什么都跑不了。

**操作步骤：**

1. 打开浏览器，访问：https://nodejs.org
2. 点击页面上大大的 **LTS** 按钮（推荐版本，带"Recommended for Most Users"字样）
3. 下载完成后，双击安装包
4. **全程点「下一步」「Next」就行，不用改任何设置**
5. 安装完成后，按键盘 `Win + R`，输入 `cmd`，回车打开命令提示符
6. 输入以下命令并回车，如果显示版本号就说明装好了：

```bash
node -v
```

应该看到类似 `v20.x.x` 或 `v22.x.x` 的版本号。

```bash
npm -v
```

应该看到类似 `10.x.x` 的版本号。

---

### 2. 安装 MySQL（数据库，用来存数据）

> 数据库就是存放用户、房源、订单等信息的地方。

**操作步骤：**

1. 打开浏览器，访问：https://dev.mysql.com/downloads/installer/
2. 点击 **Windows (x86, 32-bit), MSI Installer** 那一行右边的 **Download**
3. 登录/注册页面可以直接点最下面的 "No thanks, just start my download." 免费下载
4. 下载完成后双击安装包
5. 选择 **Server only**（只装服务器），点 Execute → Next
6. 点击 **Execute** 安装所需组件
7. **配置页面（重要！请记住你设置的密码）：**
   - **Type and Networking** → 直接 Next（默认端口 3306）
   - **Authentication Method** → 选第一个（推荐），Next
   - **Accounts and Roles** → **这里要设 Root Password**：
     - 建议输入 `123456`（方便记，或者你自己喜欢的密码）
     - **⚠️ 一定要记住这个密码！后面要用到！**
   - 后续一直 Next → Install → Finish

8. 验证是否安装成功：在命令提示符中输入：

```bash
mysql -u root -p
```

然后输入你刚才设置的密码，如果能进入 `mysql>` 界面就成功了。输入 `exit` 可以退出。

## 第二步：复制项目到你的电脑上

把整个 **「青年公寓系统」** 文件夹复制到你电脑的任意位置，比如：

- `D:\青年公寓系统`
- 或 `C:\Users\你的用户名\Desktop\青年公寓系统`

**注意：路径中不要有中文以外的特殊符号。**

---

## 第三步：启动数据库 MySQL

每次使用本系统前，需要先确保 MySQL 在运行。

### 方法一：如果你是默认安装的（推荐）

MySQL 一般会自动设为 Windows 服务，开机自启。可以跳过这一步。

如果不确定，按 `Win + R` 输入 `services.msc` 回车，找到 **MySQL** 服务，确认状态是「正在运行」。

### 方法二：手动启动

在命令提示符中执行：

```bash
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqld.exe" --console
```

> 注意：你的 MySQL 版本可能不是 8.0，去 `C:\Program Files\MySQL\` 下面看看实际文件夹名。

看到类似 `ready for connections` 的文字就说明启动成功了。

**⚠️ 这个窗口不要关掉，关了 MySQL 就停了。**

---

## 第四步：修改数据库密码配置（重要！）

如果你安装 MySQL 时设置的 root 密码**不是空密码**，需要做这步：

1. 用记事本打开文件夹里的：`server\.env`
2. 找到这一行：`DB_PASSWORD=`
3. 改成你的密码，比如：`DB_PASSWORD=123456`
4. 保存文件（Ctrl+S）

> 如果你设的是空密码（直接回车跳过），那就不用改。

---

## 第五步：安装依赖 & 初始化数据库（3行命令）

### 5.1 打开命令行终端

1. 进入项目文件夹（资源管理器中打开 `青年公寓系统`）
2. 在文件夹空白处 **按住 Shift + 右键**
3. 选择 **「在此处打开 PowerShell 窗口」** 或 **「在此处打开命令窗口」**

### 5.2 安装后端依赖

在弹出的黑色窗口中，依次输入以下命令（每输一行按一次回车）：

```bash
cd server
npm install
```

> ⚠️ 这一步会下载很多文件，需要等待几分钟，取决于网速。
> 
> 如果太慢，可以使用淘宝镜像加速：先执行 `npm config set registry https://registry.npmmirror.com`

### 5.3 初始化数据库（创建表 + 导入示例数据）

```bash
node init-db.js
```

看到输出 **「数据库初始化完成！」** 就成功了！

此时数据库里会有：
- **管理员账号**: `admin` / 密码: `123456`
- **租客账号**: `zhangsan` / 密码: `123456`
- 15 条房源、若干订单/合同/缴费记录、5 条公告

### 5.4 返回根目录并安装前端依赖

```bash
cd ..
npm install
```

同样需要等一会儿。

---

## 第六步：启动系统（2 个命令）

### 6.1 启动后端服务（第 1 个窗口）

保持当前的 PowerShell 不关，或者再新开一个：

```bash
cd server
node app.js
```

看到 **「服务已启动: http://localhost:3000」** 说明后端 OK 了。

### 6.2 启动前端页面（第 2 个窗口）

**新开一个 PowerShell 窗口**（因为上一个要留着跑后端）：

```bash
npm run dev
```

看到类似这样的信息就说明启动成功了：

```
  VITE v8.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.x.x:5173/
```

**浏览器通常会自动打开页面。如果没有，手动在浏览器地址栏输入：`http://localhost:5173`**

## 常见问题（FAQ）

### Q1：提示 `npm 不是内部或外部命令`
→ Node.js 没装好，重新安装 Node.js，并且**安装完后重启电脑**。

### Q2：提示 `mysql 不是内部或外部命令`
→ MySQL 没装好，或者没有加入环境变量。建议重新安装 MySQL 并勾选添加到 PATH。

### Q3：`node app.js` 报错 `ECONNREFUSED` 或 `connect ECONNREFUSED 127.0.0.1:3306`
→ MySQL 没有启动。先按照「第三步」启动 MySQL，然后再运行。

### Q4：`node app.js` 报错 `Access denied for user 'root'@'localhost'`
→ 密码不对。检查 `server/.env` 文件中的 `DB_PASSWORD=` 是否和你安装 MySQL 时设置的密码一致。

### Q5：`npm install` 很慢或报错
→ 使用淘宝镜像加速：
```bash
npm config set registry https://registry.npmmirror.com
```
然后重新执行 `npm install`。

### Q6：页面打开了但是是空白的 / 接口报错
→ 确认**两个窗口都在运行**（后端 3000 和前端 5173），不能只开一个。

### Q7：端口被占用（Address already in use）
→ 可能上次没关干净。关闭占用端口的程序：
```bash
# 查看 3000 端口占用
netstat -ano | findstr :3000
# 查看 5173 端口占用
netstat -ano | findstr :5173
# 用上面显示的 PID 号结束进程（xxx 换成数字）
taskkill /PID xxx /F
```

### Q8：我想让其他人也能访问（手机/局域网）
→ 前端启动时已经显示了 Network 地址（如 `http://192.168.x.x:5173`），同一个 WiFi 下其他设备直接访问这个地址即可。但**后端 API 代理只在开发模式生效**，正式部署需要额外配置 Nginx 等。

## 项目结构速览

```
青年公寓系统/
├── src/                    ← 前端代码（Vue3 页面）
│   ├── views/
│   │   ├── front/          ← 前台页面（首页、房源列表等）
│   │   ├── user/           ← 用户端页面（个人中心、订单等）
│   │   ├── manager/        ← 管家端页面（订单审核等）
│   │   └── admin/          ← 管理端页面（后台管理等）
│   ├── layouts/            ← 布局组件（导航栏、侧边栏）
│   ├── api/                ← 接口调用
│   ├── stores/             ← 用户状态管理
│   └── router/             ← 路由配置
├── server/                 ← 后端代码（Node.js + Express）
│   ├── routes/             ← 路由处理
│   ├── config/             ← 配置文件
│   ├── middleware/         ← 中间件（JWT认证等）
│   ├── sql/                ← 数据库建表脚本
│   ├── .env                ← 数据库配置（密码在这里改！）
│   ├── app.js              ← 后端入口文件
│   └── init-db.js          ← 数据库初始化脚本
├── public/                 ← 静态资源
├── package.json            ← 前端依赖配置
├── vite.config.js          ← Vite 构建工具配置
├── index.html              ← 前端入口 HTML
└── 本文档.md               ← 你正在看的这份指南
```
